# Host Management

## Host Registry

All hosts are defined in `hosts/hosts.nix`. Each entry is a Nix attrset
with the following structure:

```nix
{
  hostName = "hostname";              # networking.hostName
  userName = "username";              # Home Manager user
  repoPath = "/home/user/repo";       # Path to this repo on the host
  tags = [ "tag:admin" ];             # Tailscale ACL tags
  tailnetDomain = "xxx.ts.net";       # Optional split DNS domain
  gitlabRunnerTags = [ "nixos" ];     # GitLab Runner tags
  sshAuthorizedKeys = [ "ssh-..." ];  # SSH public keys
  features = {
    secrets = true;                   # Enable SOPS secrets
    gitlabRunner = true;              # Enable GitLab Runner
    bot = true;                       # Enable Telegram bot
    tailscale = true;                 # Enable Tailscale
    tailscaleExitNode = true;         # Advertise as exit node
    ssh = true;                       # Enable SSH daemon
  };
  config = { ... };                   # Extra NixOS overrides
}
```

## Adding a New Host

### Method 1: Manual

1. Add entry to `hosts/hosts.nix`
2. Create `hosts/<name>/hardware-configuration.nix`
3. Generate host config:
   ```bash
   ivali bootstrap host <name>
   ```
4. Review generated files
5. Apply: `sudo nixos-rebuild switch --flake .#<name>`

### Method 2: From Fresh NixOS

1. Boot into fresh NixOS GNOME install
2. Open terminal, run:
   ```bash
   curl -sSL <install-url> | bash -s -- --host <name>
   ```
   Or manually:
   ```bash
   sudo nixos-rebuild switch --flake .#<name>
   ```

## Host Template

`lib/host-templates/laptop.nix` generates the full NixOS configuration
from a host spec. It handles:

- **Host identity**: `networking.hostName`
- **User account**: Creates user with standard groups
- **Sudo rules**: User gets NOPASSWD, GitLab Runner gets systemctl
- **Git config**: Safe directory for the repo
- **SOPS secrets**: All standard secrets (Tailscale, Telegram, GitLab)
- **GitLab Runner**: Configured with host-specific tags
- **Telegram bot**: Enabled with default user
- **Tailscale**: Configured with tags, exit node, split DNS
- **SSH**: Tailscale-only access with authorized keys

## Hardware Configuration

Each host needs a `hardware-configuration.nix` generated by:
```bash
nixos-generate-config --show-hardware-config > hosts/<name>/hardware-configuration.nix
```

This contains host-specific hardware details (CPU, GPU, storage, etc.).

## Per-Host Secrets

Host-specific secrets are stored in `secrets/hosts/<name>.yaml`.
These are encrypted with SOPS and decrypted at runtime.
