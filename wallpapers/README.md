# Wallpapers

Place your wallpaper images in this directory.

## Required Files

| File | Purpose |
|------|---------|
| `default.jpg` | Desktop wallpaper (dark theme recommended) |
| `lockscreen.jpg` | Lock screen wallpaper |

## Recommended

- Resolution: 3840x2160 or higher
- Format: JPEG, PNG, or WebP
- Style: Dark, abstract, or minimal for Gruvbox Dark theme
- Avoid bright/light wallpapers (they clash with dark theme)

## Automatic Switching

The Night Theme Switcher extension can automatically switch
between light and dark wallpapers at sunset/sunrise.

To use this feature, add light variants:

| File | Purpose |
|------|---------|
| `default-light.jpg` | Light desktop wallpaper |
| `lockscreen-light.jpg` | Light lock screen wallpaper |
